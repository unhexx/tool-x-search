# Дизайн: tool-x-search

## Назначение

Явный фасад. Поиск по X и `view_x_video` **не воспроизводятся локально** без платформы X / xAI. Сервис существует, чтобы агент не выдумывал локальный Twitter API.

## Поведение

- По умолчанию: `ok: false`, список server-side имён, ссылка на доку xAI.
- `TOOL_X_FIXTURES=1`: выдача из `fixtures/x.json` для герметических тестов цикла.

## Что нельзя делать в этом репо

- скрейп x.com
- неофициальные зеркала
- хранение пользовательских токенов X «на будущее» в git

Живой поиск — только server-side tools xAI в том же запросе, что и локальные client-side Tools.
